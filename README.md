# Kanji Handwrite Board

[English](./README.md) | [日本語](./README_JA.md)

A React Native handwriting board component for practicing Japanese kanji using KanjiVG stroke data.

## Features

- Japanese kanji handwriting practice
- Stroke recording
- Stroke count checking
- React Native component architecture
- KanjiVG integration
- Expo support

## Tech Stack

- React Native
- Expo
- TypeScript
- react-native-svg
- KanjiVG

## Project Structure

```txt
src/
  components/
  data/
  utils/
  types/
```

## Getting Started

Install dependencies:

```bash
npm install
```

Start Expo:

```bash
npx expo start
```
