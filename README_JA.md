# Kanji Handwrite Board

[English](./README.md) | [日本語](./README_JA.md)

KanjiVG の筆順データを使用した、日本語漢字練習用の React Native 手書きコンポーネントです。

## 機能

- 日本語漢字の手書き練習
- ストローク記録
- 画数チェック
- React Native コンポーネント構成
- KanjiVG 対応
- Expo 対応

## 技術スタック

- React Native
- Expo
- TypeScript
- react-native-svg
- KanjiVG

## プロジェクト構成

```txt
src/
  components/
  data/
  utils/
  types/
```

## 開発開始

依存関係をインストール：

```bash
npm install
```

Expo を起動：

```bash
npx expo start
```
